# Задание 10. Проверка целостности (sha256)

**Что делаем:** доказываем, что скачанный файл — это тот же файл, что
загружали, до байта.

**Зачем:** контрольная сумма — «отпечаток» файла. Если хоть один байт
изменился (битая сеть, подмена), сумма станет другой.

## Шаг 1. Посчитайте сумму скачанного файла

Оставаясь в `task09-download`:

```bash
shasum -a 256 myapp-1.0.0.tar.gz
```

Получите длинную строку из 64 символов — это sha256.

## Шаг 2. Сравните с тем, что хранит Artifactory

Сумма из задания 7 (в JSON-ответе сервера, поле `checksums.sha256`)
и сумма из шага 1 должны совпадать **посимвольно**.

Можно сравнить глазами, а можно — одной командой. ВПИШИТЕ пароль:

```bash
curl -s -u admin:____ \
  http://localhost:8081/artifactory/api/storage/myapp-local/myapp/1.0.0/myapp-1.0.0.tar.gz \
  | grep sha256
```

## Шаг 3 (эксперимент). Подмените файл и посчитайте снова

```bash
echo "кусок мусора" >> myapp-1.0.0.tar.gz
shasum -a 256 myapp-1.0.0.tar.gz
```

Сумма изменилась? После эксперимента удалите файл и скачайте заново
(задание 9, шаг 2).
