# Задание 12. Паспорт артефакта

**Что делаем:** запрашиваем у API всю информацию о файле.

**Зачем:** у каждого артефакта в Artifactory есть «паспорт»: размер,
контрольные суммы, кто и когда загрузил. Это основа аудита — всегда можно
ответить «кто привёз этот файл и когда».

## Шаг 1. Запросите информацию

```bash
cd ../task12-file-info
```

ВПИШИТЕ пароль:

```bash
curl -s -u admin:____ \
  http://localhost:8081/artifactory/api/storage/myapp-local/myapp/1.0.0/myapp-1.0.0.tar.gz
```

## Шаг 2. Найдите в ответе

- `size` — размер в байтах;
- `createdBy` — кто загрузил;
- `created` — когда;
- `checksums` — три контрольные суммы;
- `downloadUri` — ссылка для скачивания (её вы уже использовали в задании 9).

## Шаг 3. Запросите информацию о папке

Тот же endpoint работает и для папок:

```bash
curl -s -u admin:ВАШ_ПАРОЛЬ \
  http://localhost:8081/artifactory/api/storage/myapp-local/myapp/
```

В ответе — список `children`: ваши версии `1.0.0` и `1.0.1`.
Этот список пригодится в pro-заданиях.
