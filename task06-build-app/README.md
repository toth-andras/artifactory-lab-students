# Задание 6. Собираем «приложение» и архив

**Что делаем:** создаём крошечное приложение и упаковываем его в архив —
это будет наш артефакт.

**Зачем:** артефакт — это результат сборки, который мы отдаём наружу.
В жизни его собирает компилятор/сборщик, у нас — `tar`.

## Шаг 1. Перейдите в папку задания

```bash
cd task06-build-app
```

## Шаг 2. Создайте приложение

Выполните команды по очереди:

```bash
mkdir myapp
echo "print('hello from myapp')" > myapp/main.py
echo "1.0.0" > myapp/VERSION
```

Получился каталог `myapp/` с двумя файлами: программа и файл с версией.

## Шаг 3. Упакуйте в архив

```bash
tar -czf myapp-1.0.0.tar.gz -C myapp .
```

Разбор команды:
- `tar -czf` — создать (`c`) сжатый gzip (`z`) архив в файл (`f`);
- `-C myapp .` — взять всё содержимое каталога `myapp`.

## Шаг 4. Проверьте, что архив создан

```bash
ls -la myapp-1.0.0.tar.gz
tar -tzf myapp-1.0.0.tar.gz
```

Вторая команда показывает содержимое архива: там должны быть
`./main.py` и `./VERSION`.

## Результат

В папке лежит `myapp-1.0.0.tar.gz`, внутри — два файла.
