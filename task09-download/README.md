# Задание 9. Скачивание артефакта

**Что делаем:** скачиваем файл обратно из репозитория — так его забирает
сервер при деплое или коллега.

## Шаг 1. Перейдите в папку задания

```bash
cd ../task09-download
```

## Шаг 2. Скачайте файл

ВПИШИТЕ пароль вместо `____`:

```bash
curl -u admin:____ -O \
  http://localhost:8081/artifactory/myapp-local/myapp/1.0.0/myapp-1.0.0.tar.gz
```

Разбор команды:
- `-O` — сохранить ответ в файл с тем же именем, что в URL.

## Шаг 3. Проверьте, что файл скачался

```bash
ls -la myapp-1.0.0.tar.gz
```

## Шаг 4 (по желанию). Загляните внутрь, не распаковывая

```bash
tar -tzf myapp-1.0.0.tar.gz
```
