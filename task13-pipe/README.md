# Задание 13. Конвейер: достаём только sha256

**Что делаем:** из большого JSON вырезаем одно нужное значение
командой-конвейером.

**Зачем:** в скриптах некрасиво и неудобно читать весь JSON — нужно уметь
доставать отдельные поля. Это классическое применение конвейеров bash.

## Шаг 1. Впишите пароль и пропущенное слово

Перейдите в папку задания и откройте `info.sh`:

```bash
cd ../task13-pipe
```

В файле два пропуска:
1. `PASSWORD="____"` — ваш пароль;
2. `grep "____"` — ВПИШИТЕ название поля, которое ищем
   (самая надёжная контрольная сумма из трёх, мы видели её в задании 12).

## Шаг 2. Запустите

```bash
chmod +x info.sh
./info.sh
```

## Шаг 3. Как это работает

```bash
curl ... | grep "sha256" | cut -d'"' -f4
```

- `curl` — получает JSON;
- `grep "sha256"` — оставляет одну строку с нужным полем;
- `cut -d'"' -f4` — режет строку по кавычкам и берёт 4-й кусок —
  само значение.
